# Testes de sistema — a implementar

Plano: automação com Playwright + TypeScript para a interface Vue `PIM › Employee › Dependents`, cobrindo ST-01 a ST-09 em `../docs/02-plano-de-testes.md`.

- Preferir instalação local e dados de testes exclusivos; não usar a demo pública para cenários destrutivos/segurança.
- Preparar setup de autenticação, fixture de funcionário, Page Object para dependentes, captura de screenshots/traces na falha, teardown que remova somente registros criados.
- Confirmar seletores na interface instalada antes de implementá-los.
- Implementação, execução e evidências **ainda pendentes**.
