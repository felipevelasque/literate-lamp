# Testes de integração — a implementar

Metas: executar DAO + Doctrine + banco **real e isolado** e, após preparar a instalação de teste, testar a API REST de dependentes com oráculos de estado e autorização. Casos IT-01 a IT-08 em `../docs/02-plano-de-testes.md`.

- Não usar o site público para criar/eliminar dependentes nos testes de integração.
- Reutilizar a infraestrutura própria de testes da versão de OrangeHRM e dados YAML específicos, sem copiar integralmente os testes dos colegas.
- Escrever preparação/limpeza automática e registrar a versão do banco e do PHPUnit.
